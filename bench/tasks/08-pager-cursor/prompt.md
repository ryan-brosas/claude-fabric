The admin user list only ever returns the first page, so the UI cannot go further than `limit` users. Please add cursor pagination to `listUsers` and the HTTP layer: `nextCursor` in the response, `cursor` accepted on the next request, a stable order of `createdAt` then `id`, the same 1..100 limit rules and default of 20, and `InvalidCursorError` (mapped to `400 { "error": "invalid_cursor" }`) for anything that is not a cursor this service produced. `docs/api.md` has the contract we published, and the last page must report `nextCursor: null`.
